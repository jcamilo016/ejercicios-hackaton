# Hackatón Banco Popular

Este repositorio reúne una serie de desafíos diseñados para desarrollarse durante el evento **Hackatón Banco Popular**. Cada reto está orientado a explorar y explotar las capacidades de **GitHub Copilot** como asistente de desarrollo para potenciar la productividad, creatividad y solución de problemas en equipos multidisciplinarios.

La propuesta busca fomentar la colaboración entre diferentes equipos, promoviendo la innovación en escenarios reales del sector financiero y demostrando cómo la IA puede acelerar la construcción de soluciones útiles, eficientes y alineadas con necesidades de negocio.

## Objetivo del repositorio

El repositorio está organizado en varios retos, cada uno asociado a un caso de negocio o área específica, y desarrollado por equipos distintos. Los ejercicios están pensados para:

- Explorar casos de uso reales dentro del ecosistema bancario.
- Experimentar con la ayuda de GitHub Copilot para resolución de problemas y generación de soluciones.
- Fomentar el trabajo en equipo, la creatividad y la entrega de prototipos funcionales.
- Demostrar cómo la IA puede apoyar análisis, automatización, visualización y generación de valor en contextos empresariales.

## Estructura del repositorio

- `team-1-negociador-alivios-financieros/` – reto de negociación y alivios financieros.
- `team-2-dashboard-conciliacion/` – reto de conciliación entre sistemas bancarios.
- `team-3-detective-lavado-activos/` – reto de detección de lavado de activos.
- `team-4-auditor-privacidad-datos/` – reto de auditoría y protección de datos sensibles.
- `team-5-multi-agente-otorgamiento-pyme/` – reto de evaluación de crédito para pequeñas y medianas empresas.
- `team-6-cazador-fugas-capital/` – reto de detección de fugas de capital y análisis de inversión.
- `team-7-validador-contratos/` – reto de validación y revisión de contratos.
- `team-8-agente-onboarding-dinamico/` – reto de onboarding dinámico y experiencia de incorporación.
- `team-9-triage-phishing/` – reto de triage y análisis de phishing. C
- `team-10-agente-asesor-inversiones/` – reto de asesoría de inversiones.

Cada equipo trabaja sobre un caso de negocio distinto y usa los archivos ubicados en `data/` para construir la solución propuesta durante el hackatón.
